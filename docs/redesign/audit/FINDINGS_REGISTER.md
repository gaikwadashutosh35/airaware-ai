# AirAware AI: Stage 0 findings register

**Date:** 24 Nov 2026.
**Production:** https://airaware-ai.netlify.app, serving commit `257352e`.
**Report:** see [LIVE_SITE_AUDIT.md](LIVE_SITE_AUDIT.md) for how this was checked. Screenshots are in [screenshots/](screenshots/); raw measurements are in [evidence/](evidence/).

## How to read this register

- **Severity:**
  - **P0** blocks access, data integrity, the core journey, or a security or privacy promise;
  - **P1** stops people understanding the main answer or finishing a key task;
  - **P2** is significant friction, or a navigation or accessibility issue;
  - **P3** is polish or consistency.
- **Kind:**
  - **defect**: the evidence shows something wrong;
  - **recommendation**: a design or copy improvement. A visual preference is always a recommendation, never a defect.
- **Evidence type:**
  - **production**: captured on the live site;
  - **local-fixture**: the same build, with every API call answered by the repo's e2e fixtures. Used for states that can't be forced safely in production;
  - **code-trace**: read in the source and not seen on screen.
- **Verification:** every finding was checked by a second agent that tried to refute it against the same evidence. The five reviewers raised 65 findings. None was rejected, and 30 had their severity, confidence, kind or evidence corrected. Duplicates across reviewers were merged into the 44 below, with the corrected values.
- **Result:** no P0 or P1 found. 4 P2, 14 P3 defects, 26 P3 recommendations.
- **Screenshot names** follow `{prod|local}-{route}-{state}-{width}x{height}-{first|full}.jpg`.
