# AirAware AI — Glossary

| Term | Meaning |
|---|---|
| AQI | Air Quality Index; interpretation depends on the specific index system and methodology. |
| CPCB National AQI | India's national AQI framework published by the Central Pollution Control Board. |
| PM2.5 | Particulate matter with aerodynamic diameter at or below 2.5 micrometres. |
| PM10 | Particulate matter with aerodynamic diameter at or below 10 micrometres. |
| Pollutant concentration | Measured or modelled amount of a pollutant, with a stated unit and timestamp. |
| Official observation | A reading published by a verified monitoring authority/station. |
| Model forecast | A numerical model estimate for a grid and forecast time, not a local station measurement. |
| Demo data | Synthetic/test data visibly identified as demo. |
| Freshness | Whether a value is recent enough under a documented provider-specific policy. |
| Provenance | Information about where a value came from, when it applies, and how it was produced. |
| Grid resolution | Approximate spatial scale represented by a model cell; not equivalent to street-level precision. |
| Indoor source control | Reducing pollution at its source, such as cooking smoke or tobacco smoke. |
| RLS | Row Level Security, a database mechanism to restrict row access based on policy. |
| MCP | Model Context Protocol, a standard for connecting AI clients to external tools/resources. |
| Quality gate | A defined set of checks that determines whether analysis passes or fails. |
